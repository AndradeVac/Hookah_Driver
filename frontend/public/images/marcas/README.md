# Logos das marcas

Coloque aqui o logo/foto de cada marca. O nome do arquivo deve ser o nome da
marca em **kebab-case** (minúsculo, sem acento, espaços viram `-`).

O script `backend/scripts/backfill_images.py` casa por esse nome e grava o
caminho em `brands.image_url`. Qualquer extensão serve: `.png`, `.jpg`, `.webp`.
