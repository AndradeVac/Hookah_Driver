# Fotos das categorias

Coloque aqui a foto de cada categoria. O nome do arquivo deve ser o nome da
categoria em **kebab-case** (minúsculo, sem acento, espaços viram `-`).

O script `backend/scripts/backfill_images.py` casa por esse nome e grava o
caminho em `categories.image_url`. Qualquer extensão serve: `.png`, `.jpg`, `.webp`.
